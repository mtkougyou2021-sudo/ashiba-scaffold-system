# ④ Googleビジネスプロフィール整備（最優先・所要90分・完全無料）

## これが一番効きます

「名古屋 足場」で検索すると、**自然検索の結果より上に地図が3件表示されます**。
これがローカルパック（地図枠）です。

- 自然検索1位を取るより**はるかに簡単**
- 表示位置は自然検索1位より**上**
- 電話ボタンが出るので、**そのまま電話がかかってくる**
- 費用は**完全に無料**

つまり、無料で順位を上げる方法として**費用対効果が最も高いのがここ**です。

---

## 現状の問題

検索したところ、`https://mt-construction-company.business.site/`
という **「鳶 足場 工事一式 MT興業」のページが存在しています**。

これは Googleビジネスプロフィールが自動生成した簡易サイトです。
つまり**プロフィール自体は既にある**ということです。

ただし現状では：
- 本体サイト `mtkougyou.com` と紐付いていない
- 情報が古い／不完全な可能性が高い
- 社名表記が「MT興業」で、サイト側の「株式会社MT興業」と不一致

**まずここを整えるのが第一歩です。**

---

## 手順

### STEP 1：オーナー確認（15分）

1. https://www.google.com/business/ にアクセス（会社のGoogleアカウントで）
2. 「MT興業」で検索
3. 既存のプロフィールが出たら「このビジネスのオーナーですか？」→ オーナー確認へ
4. 確認方法を選ぶ
   - **ハガキ**（最も確実。1〜2週間で会社の住所に届く。届いたコードを入力）
   - 電話 / メール（選べる場合はこちらが早い）
   - 動画（店舗や事務所、看板、社用車を撮影）

> **既に誰かがオーナー確認済みの場合**：「アクセスをリクエスト」を選択。
> 以前の担当者や制作会社が持っている可能性があります。心当たりに確認してください。

### STEP 2：基本情報を埋める（20分）

| 項目 | 設定内容 | 注意 |
|------|----------|------|
| ビジネス名 | `株式会社MT興業` | **サイトと完全一致**。「足場」等を付け足さないこと（ガイドライン違反で停止されます） |
| メインカテゴリ | `足場工事業` | ⭐️最重要 |
| 追加カテゴリ | `建設会社` `解体業者` `塗装業者`（該当するもの） | 3〜5個 |
| 住所 | 【要記入】 | **サイトと1文字も違わせない** |
| 電話番号 | 【要記入】 | 携帯より固定電話が望ましい |
| **ウェブサイト** | `https://mtkougyou.com/` | ⭐️必ず設定。ここが未設定だと本体サイトに効果が流れません |
| 営業時間 | 8:00〜17:00 / 日祝休 | |
| 開業日 | 【要記入：設立年月】 | |
| サービス提供地域 | 名古屋市、および対応市町村 | |
| ビジネスの説明 | ↓下の文章 | 750文字まで |
| 属性 | 「オンライン見積もり」「現地調査無料」等 該当するもの | |

**ビジネスの説明（コピペ用）**

```
株式会社MT興業は、【要記入：市区町村】を拠点に愛知県全域で足場工事を行う専門会社です。

くさび式足場・単管足場・解体工事用足場・外壁塗装用足場の設計から組立・解体まで、自社職人が一貫して施工します。戸建住宅の外壁塗装からアパート・マンションの大規模修繕、店舗・工場の改修、解体工事まで、規模を問わず対応いたします。

隣地との離れが狭い現場や変形地など、条件の難しい現場も事前に割付図を作成してから施工するため、安全かつ効率的な足場をご提供できます。着工前の近隣挨拶、養生シートによる粉塵対策も標準で行っています。

現地調査・お見積りは無料です。図面をお持ちであれば概算見積りを当日中にお出しできます。急ぎの現場もまずはお電話ください。

【協力会社様・求人応募も随時受付中】
```

### STEP 3：写真を30枚以上入れる（30分）⭐️重要

**写真の枚数と地図順位には明確な相関があります。** ここで手を抜かないでください。

| 種類 | 枚数 | 内容 |
|------|------|------|
| ロゴ | 1 | 正方形 |
| カバー写真 | 1 | 一番きれいに組めた足場の全景 |
| 外観 | 3〜5 | 会社の看板、事務所、資材置き場 |
| チーム | 3〜5 | 朝礼、KY活動、職人の作業風景（後ろ姿でOK） |
| 施工写真 | 15〜20 | **これが本体**。着工前／組立中／完成 をセットで |
| 車両・機材 | 3〜5 | トラック、資材 |

**撮り方**：スマホで十分。ただし
- 横向き（landscape）で撮る
- 明るい時間に撮る
- 電柱や電線が入りすぎない角度で
- 他社の看板や個人宅の表札が写らないように

> **今日から「現場に着いたら1枚、終わったら1枚」を習慣に。**
> これだけで1ヶ月後に40枚溜まります。

### STEP 4：口コミを集める（継続・最重要）

**地図枠の順位は、口コミの「件数」と「新しさ」で大きく動きます。**

**依頼する相手**
1. 元請けの担当者
2. 一緒に仕事をしている塗装屋・解体屋
3. 施主（個人宅の場合）
4. 協力会社の職人

**依頼方法**
Googleビジネスプロフィールの管理画面 →「クチコミを増やす」→ 短縮URLをコピー
→ LINEやSMSでこう送る：

```
お世話になっております、MT興業の【名前】です。
先日は【現場名】の件、ありがとうございました。

もしよろしければ、Googleの口コミを一言いただけないでしょうか。
下のリンクから30秒ほどで書けます。

【URL】

お手数をおかけしますが、ご検討いただけますと幸いです。
```

**目標**：3ヶ月で10件、1年で30件。

**必ず全部に返信してください。** 返信も順位に影響します。
```
（返信例）
この度はありがとうございました。
隣地が狭く難しい現場でしたが、無事に納めることができ何よりです。
またお声がけいただけますと幸いです。
```

> ⚠️ **絶対にやってはいけないこと**
> - 口コミを買う（一発で停止処分）
> - 社員に星5を書かせる（IPで検出されます）
> - 見返り（割引・金銭）を条件に口コミを依頼する（ガイドライン違反）
>
> 正直に「書いてください」とお願いするだけにしてください。

### STEP 5：週1で投稿する（毎週5分）

管理画面 →「投稿を追加」→ 写真1枚＋2〜3行

```
（投稿例）
【名古屋市中川区】戸建住宅の外壁塗装用足場を施工しました。
隣家との離れが狭い現場でしたが、割付を調整して安全に組み上げています。
お見積りは無料です。お気軽にご相談ください。
```

投稿は7日で目立たなくなるので、**週1回**が目安。
これを続けているアカウントは「稼働している事業所」と判定され、順位が安定します。
