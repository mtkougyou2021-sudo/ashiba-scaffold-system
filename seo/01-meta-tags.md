# ① タイトル・メタタグ差し替え（所要15分／効果大）

## 現状の問題

現在のトップページのタイトルはこうなっています：

```
株式会社MT興業 - 人がつくり、人が支え、人として仕事する
```

**「足場」も地名も1文字も入っていません。**
Googleはタイトルを最重要の判断材料にするため、この状態では
「名古屋 足場」で検索されても候補にすら入りません。

理念のキャッチコピーは大切ですが、それは**ページ本文の最上部**に大きく置けば伝わります。
タイトルタグは「検索されるための欄」であって「理念を書く欄」ではありません。

---

## 差し替え内容（コピペ用）

### トップページ

**タイトル**（全角32文字以内が目安）
```
足場工事なら株式会社MT興業｜【要記入：市区町村】・愛知県全域
```

記入例：
```
足場工事なら株式会社MT興業｜名古屋市・愛知県全域
```

**メタディスクリプション**（全角120文字以内が目安）
```
【要記入：市区町村】の足場工事は株式会社MT興業へ。くさび式足場・単管足場・解体足場の設計から組立・解体まで一貫対応。安全第一の自社職人が施工します。お見積り無料、即日対応可。TEL【要記入：電話番号】
```

### タイトルを書くときの原則

1. **左に重要語**（Googleもユーザーも左から読む）
2. **「サービス名＋地名＋社名」の3点セット**
3. 全ページ違う文言にする（同じタイトルが並ぶと評価が下がる）
4. 全角32文字を超えると検索結果で「…」と切れる

## WordPressでの設定手順

### 1. SEOプラグインを入れる（無料）

`ダッシュボード → プラグイン → 新規追加` で以下のどちらかを検索してインストール・有効化：

- **SEO SIMPLE PACK**（日本製・軽量・おすすめ）
- **Yoast SEO**（高機能だが重い）

初心者なら **SEO SIMPLE PACK** で十分です。

### 2. トップページのタイトルを設定

`設定 → SEO PACK → 基本設定` タブ

- 「フロントページのタイトルタグ」→ 上のタイトルを貼り付け
- 「フロントページのディスクリプション」→ 上の説明文を貼り付け

### 3. 各ページのタイトルを設定

各固定ページの編集画面を下にスクロールすると
`SEO SIMPLE PACK設定` という欄が出るので、そこに上の表の値を入れる。

## 同時にやる4つの設定

### ① サンプルページを削除（5分）

現在 `https://mtkougyou.com/sample-page/` に
WordPressの初期状態の「サンプルページ」が公開されたままで、
**Googleにインデックスされています**。

「作りかけの放置サイト」という評価に直結するので必ず消してください。

```
ダッシュボード → 固定ページ → 「サンプルページ」にカーソルを合わせる
→ ゴミ箱へ移動 → ゴミ箱を空にする
```

投稿の「Hello world!」も同様に削除してください。

### ② パーマリンク設定を変更（5分）

```
ダッシュボード → 設定 → パーマリンク → 「投稿名」を選択 → 変更を保存
```

URLが `?p=123` のような形式だと検索エンジンが内容を理解できません。
`/company/` `/recruit/` のような英単語のURLにします。

推奨URL：

| ページ | URL |
|--------|-----|
| 会社概要 | `/company/` |
| サービス一覧 | `/service/` |
| くさび式足場 | `/service/kusabi/` |
| 単管足場 | `/service/tankan/` |
| 解体足場 | `/service/kaitai/` |
| 塗装用足場 | `/service/tosou/` |
| 施工事例 | `/works/` |
| 求人 | `/recruit/` |
| 対応エリア | `/area/` |
| お問い合わせ | `/contact/` |

### ③ Google Search Console に登録（30分・無料）

1. https://search.google.com/search-console/ にGoogleアカウントでログイン
2. 「URLプレフィックス」に `https://mtkougyou.com/` を入力
3. 所有権の確認 → 「HTMLタグ」を選択してメタタグをコピー
4. SEO SIMPLE PACK の `設定 → SEO PACK → ウェブマスターツール` に貼り付け
5. Search Console に戻って「確認」

**これをやらないと、順位が上がったのかどうかも分かりません。** 必ずやってください。

### ④ サイトマップを送信

プラグイン `XML Sitemap & Google News`（無料）を入れると
`https://mtkougyou.com/sitemap.xml` が自動生成されます。

Search Console の `サイトマップ` → `新しいサイトマップの追加` に
`sitemap.xml` と入力して送信。

これで新しいページが数日でインデックスされるようになります。

## やってはいけないこと

| ❌ NG | 理由 |
|------|------|
| タイトルにキーワードを詰め込む（`足場 名古屋 足場工事 足場屋 愛知 足場`） | スパム判定でむしろ順位が落ちます |
| 他社サイトの文章をコピーする | 重複コンテンツ判定。最悪インデックス削除 |
| 有料の「被リンク販売」サービスを使う | ペナルティ対象。無料でやる本件の方針とも矛盾 |
| 白背景に白文字でキーワードを隠す | 手動ペナルティ。一発でアウト |
