# ③ 追加すべきページと原稿（コピペ用）

## なぜページを増やすのか

Googleは**1ページしかないサイトを上位に出しません**。
「この会社について詳しく書かれている」という判断材料が無いからです。

そして重要なのは、**ページを1つ作るごとに、そのページが拾える検索キーワードが増える**こと。
トップページ1枚では「MT興業」でしか拾えませんが、
求人ページを作れば「足場 求人 名古屋」で、
くさび式足場のページを作れば「くさび式足場 名古屋 業者」で拾えるようになります。

**1日1ページ、2週間で完成します。** 上から順に作ってください。

---

## 優先順位

| 順位 | ページ | 理由 |
|------|--------|------|
| 1 | 会社概要 | 信頼性の土台。地図順位にも直結 |
| 2 | 求人 | **競合が弱く最も上位を取りやすい**。人材確保にも直結 |
| 3 | サービス（4本） | 「くさび式足場 業者」等の具体的な検索を拾う |
| 4 | 施工事例 | 中長期で最強。写真がそのまま資産になる |
| 5 | 対応エリア | 「〇〇市 足場」を面で拾う |
| 6 | お問い合わせ | 受け皿。無いと全部無駄になる |

# 2. 求人ページ `/recruit/` ← **最優先で作る価値あり**

**タイトル**：`足場職人の求人｜株式会社MT興業｜【市区町村】｜未経験歓迎`

**なぜ最優先か**：「足場 求人 名古屋」系のキーワードは、
求人媒体（Indeed等）以外の**自社サイトの競合がほとんどいません**。
さらに [02-structured-data.html](02-structured-data.html) の JobPosting を貼れば
**Google しごと検索**に無料で載り、検索結果の最上部に表示されます。

## 原稿

```
# 足場職人（とび職）募集｜未経験歓迎

## 「手に職をつけたい」なら、足場から始めてください。

足場屋は、体ひとつで始められて、腕次第でどこまでも稼げる仕事です。
20代で現場を任され、30代で独立していく職人を、私たちは何人も見てきました。

株式会社MT興業では、一緒に現場を作る仲間を募集しています。
経験は問いません。必要なのは「きちんと働く気があるか」だけです。

## 募集要項

| 項目 | 内容 |
|------|------|
| 職種 | 足場職人（とび職） |
| 雇用形態 | 正社員 ／ アルバイト |
| 仕事内容 | 住宅・店舗・工場などの足場の組立・解体 |
| 給与 | 月給【要記入】円 〜 【要記入】円（経験・能力による） |
| 日給（アルバイト） | 【要記入】円 〜 |
| 勤務時間 | 8:00〜17:00（現場により変動） |
| 勤務地 | 【要記入：市区町村】および愛知県内の各現場 |
| 休日 | 日曜・祝日、年末年始、夏季休暇、GW |
| 待遇 | 各種社会保険完備、交通費支給、資格取得支援（費用全額会社負担）、作業着支給、昇給あり、賞与あり |
| 応募資格 | 学歴不問・未経験者歓迎・普通自動車免許（AT限定可）歓迎 |

## 未経験でも大丈夫な理由

**1. 最初の3ヶ月は先輩とペアで動きます**
いきなり高い所には上げません。まずは資材の運搬と片付けから、
道具の名前と現場の流れを覚えてもらいます。

**2. 資格は会社が全額出します**
足場の組立て等特別教育、玉掛け、高所作業車、フルハーネス特別教育——
必要な資格は入社後に会社負担で取得できます。自己負担はありません。

**3. 給料は現金です**
足場は「今日いくら稼いだか」が分かりやすい仕事です。
腕が上がれば、その分きちんと上げます。

## 一日の流れ

| 時刻 | 内容 |
|------|------|
| 7:30 | 出社・積み込み |
| 8:00 | 現場到着・KY（危険予知）活動 |
| 8:30 | 作業開始 |
| 10:00 | 休憩 |
| 12:00 | 昼休憩 |
| 15:00 | 休憩 |
| 17:00 | 作業終了・片付け・帰社 |

## 応募方法

お電話またはフォームからご連絡ください。
「求人を見た」とお伝えいただければ、担当者がすぐに対応します。

TEL：【要記入：電話番号】（受付 8:00〜17:00）

まずは現場見学だけでも構いません。
実際の仕事を見てから決めていただいて大丈夫です。
```

> **写真を必ず入れてください**：現場で働く職人の後ろ姿、朝礼の風景、
> 完成した足場、会社のトラック。顔出しNGなら後ろ姿やヘルメット越しでOK。

# 3. サービスページ（4本）

## 3-1. くさび式足場 `/service/kusabi/`

**タイトル**：`くさび式足場の施工｜株式会社MT興業｜【市区町村】`

```
# くさび式足場（ビケ足場）

## 住宅・低層建築でもっとも多く使われる足場です

支柱に付いたポケットへ、手すりや踏板のくさびをハンマーで打ち込んで組み上げる足場です。
ボルトを使わないため組立・解体が速く、部材の種類も少ないため、
住宅の外壁塗装や屋根工事、小規模な改修工事で広く採用されています。

## こんな工事に適しています

- 戸建住宅の外壁塗装・屋根塗装
- アパート・マンションの大規模修繕
- 3〜5階程度の店舗・事務所の改修
- 屋根の葺き替え・雨樋の交換

## MT興業のくさび式足場の特徴

**1. 敷地条件に合わせて図面から起こします**
隣地との離れが狭い、庭木がある、駐車場を潰せない——
現場ごとの制約に合わせて、事前に割付図を作成してから組み立てます。

**2. 職人が作業しやすい高さで組みます**
段の高さが合っていない足場は、作業効率も安全性も落ちます。
軒天の高さや作業内容から逆算して、踏板の位置を決めています。

**3. 近隣への配慮を徹底します**
くさび式はハンマーで打ち込むため、どうしても音が出ます。
着工前の近隣挨拶、作業時間の厳守、養生シートでの粉塵対策を標準で行っています。

## 対応可能な規模

| 項目 | 対応範囲 |
|------|----------|
| 高さ | 【要記入：例）地上45mまで】 |
| 用途 | 塗装・改修・解体・新築 |
| 対応エリア | 愛知県全域 |

## お見積りは無料です

現地調査・お見積りに費用はいただきません。
図面をお持ちであれば、概算のお見積りは当日中にお出しできます。

TEL：【要記入：電話番号】
```

# 4. 施工事例 `/works/` ← 中長期で最強

**タイトル**：`施工事例｜株式会社MT興業の足場工事実績`

**作り方**：WordPressの「投稿」で1件1記事。カテゴリを「施工事例」にする。
1件あたり**写真3〜5枚＋本文200〜400字**。10分で書けます。

## 1件あたりのテンプレート

```
# 【工事名】｜【市区町村】｜【建物種別】

## 工事概要

| 項目 | 内容 |
|------|------|
| 施工場所 | 愛知県【市区町村】 |
| 建物種別 | 木造2階建て戸建住宅 |
| 工事内容 | 外壁塗装用くさび式足場の組立・解体 |
| 足場面積 | 約【　】㎡ |
| 工期 | 組立1日／解体1日 |
| 施工時期 | 【　】年【　】月 |

## 現場の状況と対応

【100〜200字。例】
隣家との離れが約400mmしかない現場でした。
通常の割付では組めないため、東面のみ壁つなぎの位置を変更し、
支柱を1スパン狭めて対応しました。
隣家の外壁を傷つけないよう、接触部には全て緩衝材を入れています。

## 施工写真

（着工前／組立中／完成／解体後 の4枚）
```

## 施工事例が最強な理由

- 現場写真は**他社が絶対にコピーできない**唯一のコンテンツです
- 「【市区町村名】＋足場」の検索を、事例の数だけ面で拾えます
- 元請けや施主が発注前に必ず見るのが施工事例です
- **週1件で1年後に50ページ**。これが競合との決定的な差になります

> **写真を撮るときのコツ**
> 現場に着いたら「着工前」、組み上がったら「完成」を必ず1枚。
> スマホでOK。撮る習慣さえつけば、あとは流し込むだけです。

# 6. お問い合わせページ `/contact/`

**タイトル**：`お問い合わせ・無料見積り｜株式会社MT興業`

プラグイン **Contact Form 7**（無料）で作成します。

## フォーム項目（これ以上増やさない）

| 項目 | 必須 |
|------|------|
| お名前 | 必須 |
| 会社名 | 任意 |
| 電話番号 | 必須 |
| メールアドレス | 必須 |
| お問い合わせ内容 | 選択（見積依頼／求人応募／協力会社／その他） |
| 現場の場所 | 任意 |
| ご要望 | 任意 |

> **項目を増やすほど問い合わせは減ります。** 上記が上限だと考えてください。

## ページ冒頭に必ず置く文言

```
## お見積り・現地調査は無料です

お電話が一番早く対応できます。

# 【要記入：電話番号】
受付時間 8:00〜17:00（日曜・祝日除く）

図面をお持ちの場合は、概算のお見積りを当日中にお出しできます。
求人へのご応募、協力会社様からのご連絡もこちらで承ります。
```

> **電話番号は全ページのヘッダーに、タップで発信できる形で置いてください。**
> 現場の人間はスマホで見て、その場でかけます。
>
